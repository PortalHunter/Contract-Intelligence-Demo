The actual demo pipeline

01 · Download synthetic PDF samples

Each sample is generated from fictional material and contains 100 printable pages.

02 · Load the PDF files

Your browser computes SHA-256 fingerprints against the known fixtures. Other files are rejected, even if renamed.

03 · Produce fixture-backed rows

The recognized document identities select predetermined example clause references and simulated candidate classifications.

04 · Inspect and review

Each row links to a synthetic document and physical page number. Review flags are interactive but temporary.

05 · Export results

CSV is generated locally. Refreshing the page clears all files, results and review states.

What the public demo does not do

  • No general PDF text extraction or OCR
  • No real FAR/DFARS regulatory source matching
  • No subcontract fact-based flow-down determination
  • No AI interpretation or legal approval
  • No file transfer, account, cloud processing or stored history

These capabilities belong to the separate, private offline application. This website demonstrates the interaction pattern using synthetic, fingerprint-verified fixtures.
